# Astra Client 1.24.0 validation

## Build, animation, audio and archive checks

- Built Member/Premium for Java 21, Minecraft 1.21.11 and Fabric Loader 0.19.3. Required native Windows-media ABI, six-theme scene/layout, curved mesh, blind-pore and voice-gating tests passed.
- Added CharacterAnimationTest: eyelid timing, periodic and bounded blinking, bounded sweat rise/fade and interpolated speech-envelope samples, including before/after a clip and missing-data handling.
- Generated 648 streamed Ogg clips, four variants per 27 events for six characters. Two new personality-specific variants precede the previous two. Audio has character-specific baked pitch/timbre profiles; Sandy uses a public-domain U.S. LJ Speech voice. DrDonutt uses an original unmodified generic voice. Source, processing, licenses and model hashes are in CHARACTER_VOICES.md and the bundled attribution file.
- Each clip has a precomputed, bounded, nonempty 25-Hz RMS mouth envelope. Runtime only interpolates the samples; the speech engine, models, audio-analysis tooling, Python and FFmpeg do not ship or run with Minecraft. Captions and streamed sound resources resolve for every entry.
- Geometry generator now defines 255 base primitives and seven articulated face details per character: two eyelids, four highlighted sweat beads and a speech mouth. Sweat paths are sampled on the curved skin surface. Clothing seams, hair strands, fur tufts, shell joints and a recessed Patrick belly button supplement the existing closed pores/material shading. World/preview models share cached geometry and have independent poses.
- Final archives differ only by edition/version metadata. Original Jamble, PvP, backgrounds, media, totem resolution, hand-size and existing packet/action/food-observation hooks remain byte-identical to 1.23.0, alongside the character render guards. No withdrawn payment features, runtime scripts/executables, synthesis models or excluded fixtures ship. Exact original nested Freelook SHA-256 remains fe1a32d9e4b8894122f52985c9d81b5cefa7bb7b67e67d17e8d03c495f8ba1e4.

## Actual packaged Minecraft checks

Used excluded observation helpers and a local world with the packaged Premium, then the final Member:

- Seeded the previous config with speech Off and no migration flag. Starting 1.24.0 enabled speech automatically and saved the one-time migration marker. Selecting a character produced an immediate native greeting and an active Voice/Speech sound instance without visiting settings.
- Native F5 mouth parts became visible and changed scale while the clip's interpolated RMS envelope changed. Quiet/finished speech closed the mouth. Actual low health produced increasing sweat and visible 3D beads on all six rendered characters; screenshots inspected the real models and gallery.
- Sustained low health was isolated by temporarily disabling natural regeneration in the test world; ordinary regeneration in an earlier test healed the player before the deliberately high sweat assertion could be reached. Natural regeneration was restored afterward. No production behaviour was changed for that fixture condition.
- Four successive totem reaction tests selected four distinct active native sound resources. All six selected-character greetings used their own audio resources. Nonlocal entity events stayed silent. Existing native walk animation, 3D extents/cache reuse and 36 Premium item-transform contracts passed.
- Actual menu clicks toggled Animated Details, hiding speech/sweat additions, then restored them. Voice Off stopped current audio; selecting another character automatically enabled its greeting again. Gallery/voice pages remained clickable at 1280x720 and 640x480.
- Saved manual mute with the migration marker and restarted the final Member edition. Confirmed mute remained Off; selecting Patrick or Sandy enabled the corresponding native greeting. Checked the final top-right moon logo beside the retained profile head/rank and controls. Native pause froze the RMS clock, and Small Totem remained unchanged.

The first observation attempt read a stale previous-version report while the excluded observer was baking its first model; it was retried after the report was ready. This was test-helper timing, not a client crash. Source tests/observers, synthetic event triggers, screenshots and runtime data are excluded from installable JARs. Native tests used Linux/software graphics and an OpenAL null sink: audio resource activation and decoding were checked, without a Windows listening test, live authenticated DonutSMP session or GPU FPS benchmark. Character-inspired voices are not official recordings or exact actor matches; visual additions are stylised models rather than photorealism. Existing Defender limitations remain in SECURITY.md and the limited-coverage scan report.
