# Astra Client

A cosmetic Fabric client for Minecraft Java 1.21.11, Java 21 and Fabric Loader 0.19.3 or newer. Requires Fabric API 0.141.6+1.21.11.

[Download Astra Client 1.4.3.jar](https://raw.githubusercontent.com/fragng/astra-client/main/downloads/astra-client-1.4.3.jar)

Replace the previous Astra jar in your mods folder. Press **Right Shift** in a world to open the menu.

**New in 1.4.3:** Visuals → Bubble Font. On uses rounded bubble lettering; Off restores the normal Minecraft font. Changes apply immediately and are saved across restarts.

[Download source and build instructions](https://raw.githubusercontent.com/fragng/astra-client/main/downloads/astra-client-1.4.3-source.zip)

Includes menu themes, menu-only brightness, native FOV and music settings, HUD preferences, and optional Windows Spotify desktop controls. Live Windows Spotify playback remains unverified in the Linux development environment.
