### Install

1. Download the complete Crystal FPS pack using the link above.
2. Create a separate Fabric 1.21.11 instance using Fabric Loader **0.19.3 or newer** and Java 21.
3. Extract the ZIP and copy its `mods` folder into that instance’s game directory. It contains six JARs.
4. Launch Minecraft. Press **Right Shift** in a world to open performance settings.

### Included

- A modern white home screen with the Crystal logo and local-time Jack greeting.
- 28 additional personalised welcome lines.
- Fast and Maximum FPS profiles using real Minecraft settings, with Balanced restoration and preservation of manual edits.
- An optional actual FPS HUD and configurable menu/inactive-window FPS limits.
- Original stable Sodium 0.8.14, Lithium 0.21.4, FerriteCore 8.2.0, ImmediatelyFast 1.14.3 and Fabric API 0.141.6+1.21.11.

The standalone Crystal JAR supplies branding, UI and presets. Use the complete performance ZIP to install the optimization mods too. Credits, licenses and corresponding LGPL sources are included. The full Crystal source ZIP is linked above.

### Validation

Built with Java 21 and tested in actual Minecraft 1.21.11 with the full mod set: navigation, video preset changes/restoration, manual-edit preservation, Right Shift in a world, responsive layouts, saved settings after a fresh restart and clean Quit. Tests used Linux/X11 with Mesa software rendering; FPS gains vary by hardware and world.

ClamAV 1.5.4 scanned the final Crystal JAR, performance ZIP and source ZIP: **0 infected files**. This is not Microsoft Defender certification. The linked scan report and SHA-256 checksums identify the checked files.
