# Astra Client security review — 1.28.1 (script-free bridge retained from 1.14.2)

A Microsoft Defender threat alert was reported by a friend of the client owner for the latest public version (1.14.0). The exact Defender detection name, affected filename and file hash were not available. The report is taken seriously; the recommended download links were paused during investigation, and both 1.14.0 installable JARs were withdrawn from the default branch (source/history retained). No claim is made that the report was a false positive or that Defender has cleared the replacement.

Version 1.26.0 changes only bundled character geometry, its cached surface fitting, the DrDonutt description and release metadata. It retains the completed `.gg/astrayt` invite update from 1.25.1. The new surface grid is local JSON data processed when a model is built; it creates no service, account request or runtime process. Existing audio and media integration are unchanged.

Version 1.27.0 replaces the resettable local Premium timer with offline Ed25519-signed grants bound to a launcher UUID and a fixed 30-day period from issuance. Public releases contain the verification key and hashed account bindings; the exact owner UUID is not printed in current public instructions or code. The separately supplied owner key stays outside public source/downloads. `/client <username>` requires the JackJ25 UUID and a matching private key, resolves the public recipient profile through Microsoft's Minecraft HTTPS API on a background worker, and writes a copy of the current mod to `astra-premium-exports`. No access token or private key is sent. It copies assets and the original dependency, embeds the signed grant, and leaves the installed mod untouched. It starts no helper process. The public owner Premium file is assigned specifically to JackJ25; public build flags alone grant no access. Signature verification covers the recipient UUID/name, serial and issuance/expiry dates. Modified, expired, missing or wrong-account grants use Member mode.

This is not a first-launch claiming service or unbreakable DRM. The unchanged client trusts the launcher's UUID and device clock; custom/offline identity spoofing, changed client code and clock/data tampering are outside the restriction. No server means no central revocation, no invalidation of older downloads and no synchronized first-use claim. A renewal is a separate grant with its own expiry. Ed25519 license signatures do not constitute Authenticode/JAR code signing or Defender clearance. See OWNER_SETUP.md for private-key handling. Native tests use excluded local identity fixtures without real Minecraft tokens.

The new Characters Work In Progress gate and progress use a fixed calendar window ending 15 December 2026 at 00:00 Europe/London; no new network request is involved. Previously saved character/voice effects are suppressed until release. Existing model assets and audio remain unchanged.

Version 1.28.1 adds a local case game, quota/collection persistence, manual-ticket claim references, local cosmetic render layers and a native personal-skin item renderer. Draws use SecureRandom and are committed to an account-fingerprint-scoped JSON ledger before the animation; a failed save blocks the opening. The reel displays that fixed outcome, including after reopening. Local state uses atomic replacement and bounded claim history; per-win local claim archives remain available. Resets do not erase quota or ownership. This is not an authoritative anti-fraud system: a modified client, edited files or clock/data copying can bypass local counts or invent claims. Claim IDs and screenshots are bookkeeping for manual Discord review, not cryptographically verified proof of a real draw. Rewards do not automatically assign roles or create Premium entitlements. No new reward server, payment, account-token request, Discord bot or message sender is added. The existing Discord link confirmation is used only when the player clicks it.

The owner-only issuer now also signs Lifetime grants with an authenticated maximum-expiry marker under the existing version-2 signature domain. Existing monthly grants remain valid and retain their expiry. The private key is still separate; no case result can call the issuer or bypass its account/key checks. Editing a month grant into a Lifetime one invalidates its signature. Source and public JARs include only the public key and hashed account identifiers.

Crown/wings use cached curved geometry and native player render layers filtered to the local player. The personal totem uses Minecraft's native classic/slim models and the already-loaded skin identifier; it performs no skin download, image readback/decoding, resource reload or filesystem work during item hover/render. Model selection changes only the render identifier, leaving the actual item stack/server data unchanged. Shared skin textures remain owned by Minecraft. Generated reward artwork is bundled locally. Decorations respect animation/performance preferences.

Version 1.28.1 changes only the case reel timing/easing and its local native UI sounds. The reel runs in Performance Mode while the explicit animations-Off preference remains static. Sound playback is tick-driven, rate-limited, gated by the existing sounds preference and uses bundled Minecraft sounds. Results, odds, quota, ownership, claims and licensing are unchanged. No endpoint, dependency, executable or helper was added.

## Replacement implementation

The prior Windows Spotify integration launched a bundled PowerShell script using an encoded command and hidden window. It read Windows media sessions, but that unnecessary execution mechanism can resemble patterns security products flag. Version 1.14.2 removed the script and process launcher entirely and uses the Windows Media Control WinRT APIs directly through Minecraft's existing JNA dependencies.

The installable JAR contains no PowerShell/batch/shell scripts or EXE/DLL files. The media bridge does not disable protection, create exclusions, bypass execution policy, add persistence, install a service, start a child process or download/run a helper. The Java source remains readable and included. The only bundled mod dependency is the exact original Freelook 1.2.8 JAR, SHA-256 `fe1a32d9e4b8894122f52985c9d81b5cefa7bb7b67e67d17e8d03c495f8ba1e4`; its bytecode was reviewed for process/network/native loading, with only its normal configuration file I/O found.

Astra's lyric service uses HTTPS to LRCLIB with the selected song's title/artist/album/duration. The Discord link opens through Minecraft's native user confirmation. Other custom preferences stay in the instance's config directory. Astra 1.15.1 removes the per-process Windows taskbar app-ID override; the bundled window logo remains. No registry or pinned-shortcut changes are made.

## What was verified

- Java 21 / Minecraft 1.21.11 / Fabric Loader 0.19.3 builds and real Linux Minecraft UI/native-window checks.
- Real native JNA callback/vtable tests for GUIDs/slots, Spotify filtering, UTF-16 metadata, timeline/controls, command results, async failure/cancellation/timeout, bounded session counts and COM/HSTRING/apartment cleanup. Run `./gradlew testWindowsMediaAbi` or `./gradlew check`.
- Archive inspection for unexpected scripts/native executables and nested dependencies. Test fixtures and runtime data are excluded from the installable JAR.
- ClamAV 1.5.4 using verified official daily database 28184 (15 Nov 2026) and bytecode database 339. The main database download was CDN rate-limited; no bypass/retry of that cooldown was attempted. This is limited signature coverage, not a full antivirus assurance. The scan of the previous 1.14.0 JARs also found no detections, which does not invalidate the reported Defender alert.

## Limits and reporting

Live Windows Spotify and Microsoft Defender were not available on this Linux test host. Native ABI-contract tests are not a live Windows integration test. Microsoft Defender may apply different signatures or cloud reputation. There is no guarantee that any antivirus will accept the file.

Keep Defender and browser protection enabled. Do not restore a quarantined download, add an exclusion, rename/disguise the file to evade scanning, or turn protection off to use Astra. If a replacement is flagged, keep the block and record the exact Protection history threat name, affected filename, version and SHA-256. Compare against the published SHA256SUMS file and use only the public repository's download links. A vendor false-positive submission requires that concrete information and can be made through Microsoft's official file-submission service.

The complete source ZIP naturally includes standard Gradle build scripts; the no-scripts statement above describes the installable mod JAR, not the developer build tools.
